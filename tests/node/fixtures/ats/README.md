# Hand-written ATS form fixtures

These are **representative contract fixtures written by hand** from the general,
publicly visible structure of each platform's application form. They were NOT
captured from a live site (no live probing is done without the owner's say-so),
so they prove how JobAgent handles that *shape* of form, not that any real
employer's current form works. `docs/SUPPORT_MATRIX.md` keeps "live run: none"
for every platform until a supervised live run is recorded.

All names and addresses are fictional (example.test).

- `workday_experience.html` — a Workday-shaped "My Experience" step (an "Add" per job and degree that reveals an entry form). Hand-written; used by `repeatedSections.test.js` (audit A3).
